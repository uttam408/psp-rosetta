How it's built

Adapter
The circulating SWF is a dead-MochiAds wrapper; a self-keyed RC4+zlib unwrap gets the real game out, then ffdec exports 30 sprites, 17 sounds, 128 AS3 classes.
Pipeline
Adapters emit a common IR → converters cut sprite sheets into ≤512 POT atlases and encode .ptx → assets.pak with an @index binary table.
Spec
spec/luftrauser.toml → a C header of 67 constants, every one citing its Player.as:NNN. Zero magic numbers in the port; fidelity is diff-able.
Runtime
A FlashPunk-shaped core in C — the coupled speed/direction/hspeed/vspeed accessors, the LCG (seed×16807 % 2⁷¹), fixed 30 Hz sim. SDL backend now; pspgu next.
